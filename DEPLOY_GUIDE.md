# 📱 TEMPLE SOUND ENGINE — TELEGRAM MINI APP
## Полная инструкция по развертыванию

## 📋 ЧТО ВЫ ПОЛУЧИЛИ

В папке `telegram-app` находятся:
- `index.html` — главный файл приложения
- `audio.js` — аудиоядро Temple Sound Engine
- `logo.png` — логотип приложения

---

## 🚀 ШАГ 1: СОЗДАНИЕ TELEGRAM БОТА

1. **Откройте Telegram** и найдите бота **@BotFather**

2. **Создайте нового бота:**
   ```
   /newbot
   ```
   - Введите название бота (например: "Temple Sound Engine")
   - Введите username бота (например: "TempleSoundBot")
   - Сохраните TOKEN, который даст BotFather

3. **Настройте описание:**
   ```
   /setdescription
   ```
   Предложенный текст:
   ```
   Temple Sound Engine — generative binaural audio for meditation, 
   focus, and altered states of consciousness. Real-time frequency 
   generation. Use headphones.
   ```

4. **Добавьте фото профиля:**
   ```
   /setuserpic
   ```
   Загрузите файл `logo.png`

---

## 🌐 ШАГ 2: РАЗМЕЩЕНИЕ ФАЙЛОВ НА ХОСТИНГЕ

Вам нужен веб-хостинг с HTTPS. Варианты:

### ВАРИАНТ А: GitHub Pages (БЕСПЛАТНО)

1. **Создайте GitHub аккаунт** (если нет): https://github.com

2. **Создайте новый репозиторий:**
   - Нажмите "New repository"
   - Название: `temple-sound-app` (любое)
   - Выберите "Public"
   - Создайте

3. **Загрузите файлы:**
   - Нажмите "uploading an existing file"
   - Перетащите все файлы из папки `telegram-app`:
     * index.html
     * audio.js
     * logo.png
   - Нажмите "Commit changes"

4. **Включите GitHub Pages:**
   - Перейдите в Settings → Pages
   - Source: выберите "main" branch
   - Сохраните
   - Через 1-2 минуты получите ссылку вида:
     ```
     https://ВАШ-USERNAME.github.io/temple-sound-app/
     ```

### ВАРИАНТ Б: Netlify (БЕСПЛАТНО)

1. **Зарегистрируйтесь** на https://netlify.com

2. **Создайте новый сайт:**
   - "Add new site" → "Deploy manually"
   - Перетащите папку `telegram-app`
   - Получите ссылку вида:
     ```
     https://случайное-имя.netlify.app
     ```

3. **Настройте домен (опционально):**
   - Site settings → Domain management
   - Можете изменить имя поддомена

### ВАРИАНТ В: Vercel (БЕСПЛАТНО)

1. **Зарегистрируйтесь** на https://vercel.com

2. **Импортируйте проект:**
   - "Add New" → "Project"
   - Загрузите файлы
   - Deploy

## 🔗 ШАГ 3: ПОДКЛЮЧЕНИЕ ПРИЛОЖЕНИЯ К БОТУ

1. **Вернитесь к @BotFather** в Telegram

2. **Создайте Web App:**
   ```
   /newapp
   ```
   - Выберите вашего бота
   - Название: "Temple Sound Engine"
   - Описание: "Binaural audio generator"
   - Загрузите `logo.png` как иконку
   - **Введите URL:** вашу ссылку с хостинга
     Например: `https://ВАШ-USERNAME.github.io/temple-sound-app/`
   - Short name: `temple` (или любой короткий идентификатор)

3. **Настройте кнопку меню:**
   ```
   /setmenubutton
   ```
   - Выберите вашего бота
   - Текст кнопки: "🎵 Open App"
   - URL Web App: выберите созданное приложение

---

## ✅ ШАГ 4: ТЕСТИРОВАНИЕ

1. **Откройте вашего бота** в Telegram

2. **Нажмите кнопку "Open App"** (или "Menu" → "Open App")

3. **Проверьте функционал:**
   - ✓ Приложение открывается в полный экран
   - ✓ Логотип отображается
   - ✓ 5 кнопок режимов работают
   - ✓ При запуске появляется кнопка "Stop"
   - ✓ Аудио генерируется (нужны наушники!)

## 💰 ШАГ 5: НАСТРОЙКА ПЛАТЕЖЕЙ (ОПЦИОНАЛЬНО)

Если хотите сделать приложение платным:

### ВАРИАНТ 1: Telegram Stars (встроенная валюта)

1. **Подключите платежи через BotFather:**
   ```
   /mybots → Выберите бота → Payments
   ```

2. **Добавьте проверку подписки в код:**
   ```javascript
   // В начале index.html после инициализации
   tg.ready();
   
   // Проверка платежа
   fetch('https://api.telegram.org/bot<YOUR_TOKEN>/getChat?chat_id=' + tg.initDataUnsafe.user.id)
     .then(response => response.json())
     .then(data => {
       // Проверьте статус подписки
       if (!data.result.has_paid) {
         // Покажите окно оплаты
         tg.showPopup({
           title: 'Premium Access',
           message: 'Subscribe to unlock all modes',
           buttons: [{type: 'ok', text: 'Subscribe'}]
         });
       }
     });
   ```

### ВАРИАНТ 2: Внешняя платёжная система

Интегрируйте Stripe, PayPal или YooKassa через серверную часть

## 🔧 НАСТРОЙКА И КАСТОМИЗАЦИЯ

### Изменить цвета:
В `index.html` найдите блок `<style>` и измените:
```css
--accent-color: #c9b299;  /* Основной акцентный цвет */
```

### Изменить логотип:
Замените файл `logo.png` на свой (рекомендуемый размер: 512x512px)

### Изменить режимы:
В `index.html` найдите блок с кнопками режимов и отредактируйте:
- `data-mode` — идентификатор режима (должен совпадать с audio.js)
- Эмодзи иконку
- Название режима
- Описание

### Добавить аналитику:
Вставьте код Google Analytics или Yandex.Metrika в `<head>` секцию

## ❓ ЧАСТЫЕ ВОПРОСЫ

**Q: Звук не работает**
A: Убедитесь, что:
- Используете HTTPS (обязательно для Web Audio API)
- Пользователь взаимодействовал с приложением (клик по кнопке)
- Используются наушники
- audio.js подключен корректно

**Q: Приложение не открывается**
A: Проверьте:
- URL доступен по HTTPS
- В BotFather указан правильный URL
- Нет ошибок в консоли браузера (F12)

**Q: Как обновить приложение?**
A: Просто загрузите обновлённые файлы на хостинг. 
   Изменения отобразятся автоматически (может потребоваться очистка кэша)

**Q: Можно ли добавить больше режимов?**
A: Да! Добавьте новые состояния в `audio.js` (в объект STATES),
   затем добавьте соответствующие кнопки в `index.html`
