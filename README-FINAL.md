## 🔍 ТЕСТИРОВАНИЕ:

### В браузере (для разработки):
1. Откройте `index.html` в браузере
2. Откройте консоль (F12)
3. Нажмите на любой режим
4. Проверьте логи в консоли
5. Звук должен начать генерироваться

### В Telegram (финальное тестирование):
1. Откройте бота
2. Нажмите "Open App"
3. Выберите режим
4. Проверьте звук (ОБЯЗАТЕЛЬНО В НАУШНИКАХ!)
5. Проверьте кнопку Stop
6. Проверьте переключатель языков

## 🐛 ОТЛАДКА:

### Если звук не работает:

1. **Откройте консоль браузера** (F12)
   - Смотрите ошибки красным цветом
   - Проверьте логи: "Audio started for mode: ..."

2. **Проверьте файлы**:
   ```
   ✓ index.html загружен
   ✓ audio.js загружен
   ✓ logo.png загружен
   ```

3. **Проверьте HTTPS**:
   - Web Audio API требует HTTPS
   - GitHub Pages автоматически даёт HTTPS
   - Локальное тестирование: используйте расширение Live Server

4. **Проверьте наушники**:
   - Бинауральные ритмы работают ТОЛЬКО в наушниках
   - Bluetooth может давать задержки
   - Лучше проводные наушники

### Типичные ошибки:

**"TempleAudio not found"**
→ Файл audio.js не загрузился. Проверьте путь.

**"AudioContext was not allowed to start"**
→ Сначала кликните по странице, потом запускайте звук

**"Mixed Content"**
→ Используйте HTTPS для всех файлов
